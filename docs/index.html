Xady Framework

Professional module framework for Minecraft bots

Xady is a module system built for Mineflayer-based Minecraft bots, inspired by Spigot API architecture.

Features

📦

Module System

Spigot-like plugin architecture

⚡

Event System

Decorator-based event handling

🎯

Command API

Define commands via module.yml

🔌

Service System

Inter-module communication

Installation

Requirements

  • Node.js 18+ (embedded in production)
  • TypeScript 5+ (for development)

Directory Structure

tree 
%APPDATA%\Xady\
  ├─ modules\          # Module files (.xext)
  ├─ config\           # xady.config.json
  └─ data\             # Module data

Quick Start

1. Create module.yml

yaml 
name: MyModule
version: 1.0.0
main: src/index.js
description: My first module
author: Your Name
commands:
  hello:
    description: Hello command
    usage: !hello [name]

2. Module Code

typescript 
export default class MyModule extends Xady.Module {
    onEnable() {
        this.getLogger().info("Module enabled!");
        
        // Get command from module.yml
        const cmd = this.getCommand("hello");
        if (cmd) {
            // Set executor (class instance)
            cmd.setExecutor(new HelloCommandExecutor());
        }
    }
    
    onDisable() {
        this.getLogger().info("Module disabled!");
    }
}

// Command Executor Class
class HelloCommandExecutor implements Xady.CommandExecutor {
    onCommand(sender: Xady.CommandSender, command: Xady.PluginCommand, label: string, args: string[]): boolean {
        const name = args[0] || "World";
        sender.sendMessage(`Hello, ${name}!`);
        return true;
    }
}

3. Usage

Commands use ! prefix in Xady:

  • !hello - Displays "Hello, World!"
  • !hello John - Displays "Hello, John!"

Lifecycle

Loading Order

  1. constructor() - Module loaded
  2. onLoad() - Pre-initialization
  3. onEnable() - Module enabled
typescript 
export default class MyModule extends Xady.Module {
    onLoad() {
        // Load config, prepare resources
        this.saveDefaultConfig();
    }
    
    onEnable() {
        // Register events
        this.registerEvents(new MyListener());
        
        // Setup commands
        this.setupCommands();
    }
    
    onDisable() {
        // Cleanup
    }
}

Event System

Xady uses a decorator pattern similar to Spigot API:

typescript 
// Listener class implements Listener interface
class MyListener implements Xady.Listener {
    @Xady.EventHandler(Xady.EventPriority.NORMAL)
    onMessage(event: any) {
        const msg = event.getMessage();
        console.log("Chat:", msg);
    }
}

Creating Listeners

typescript 
export default class MyModule extends Xady.Module {
    onEnable() {
        this.registerEvents(new ChatListener());
    }
}

// Listener class must implement Listener interface
class ChatListener implements Xady.Listener {
    @Xady.EventHandler(Xady.EventPriority.NORMAL)
    onChat(event: any) {
        const msg = event.getMessage();
        
        if (msg.includes("hello")) {
            event.getBot().chat("Hi!");
        }
    }
    
    @Xady.EventHandler(Xady.EventPriority.HIGH)
    onPlayerJoin(event: any) {
        console.log("Player joined!");
    }
}

Important: All listener classes must implement Xady.Listener interface for decorators to work correctly.

Priority System

Events execute in priority order:

  • LOWEST (0) - Executes first
  • LOW (1)
  • NORMAL (2) - Default
  • HIGH (3)
  • HIGHEST (4)
  • MONITOR (5) - Executes last, observation only
typescript 
@Xady.EventHandler(Xady.EventPriority.LOWEST)
onEarlyEvent(event: any) {
    // Runs first
}

@Xady.EventHandler(Xady.EventPriority.MONITOR)
onMonitorEvent(event: any) {
    // Runs last, even if event is cancelled
}

Creating Executors

Basic Executor

typescript 
class BalanceCommandExecutor implements Xady.CommandExecutor {
    onCommand(sender: Xady.CommandSender, command: Xady.PluginCommand, label: string, args: string[]): boolean {
        if (args.length === 0) {
            sender.sendMessage("Your balance: 100 coins");
            return true;
        }
        
        const player = args[0];
        sender.sendMessage(`${player}'s balance: 50 coins`);
        return true;
    }
}

Executor with Module Reference

typescript 
export default class EconomyModule extends Xady.Module {
    private balances: Map = new Map();
    
    onEnable() {
        const balCmd = this.getCommand("balance");
        if (balCmd) {
            // Pass module instance to executor
            balCmd.setExecutor(new BalanceExecutor(this));
        }
    }
    
    getBalance(player: string): number {
        return this.balances.get(player) || 0;
    }
}

class BalanceExecutor implements Xady.CommandExecutor {
    constructor(private module: EconomyModule) {}
    
    onCommand(sender: Xady.CommandSender, command: Xady.PluginCommand, label: string, args: string[]): boolean {
        const balance = this.module.getBalance("player");
        sender.sendMessage(`Balance: ${balance} coins`);
        return true;
    }
}

Async Executor

typescript 
class AsyncCommandExecutor implements Xady.CommandExecutor {
    async onCommand(sender: Xady.CommandSender, command: Xady.PluginCommand, label: string, args: string[]): Promise {
        sender.sendMessage("Processing...");
        
        // Async operation
        await this.doSomethingAsync();
        
        sender.sendMessage("Done!");
        return true;
    }
    
    private async doSomethingAsync(): Promise {
        return new Promise(resolve => setTimeout(resolve, 1000));
    }
}

Chat Pattern Matching

Register chat patterns using registerChatPattern and handle them with EventHandler:

typescript 
export default class MyModule extends Xady.Module {
    onEnable() {
        // Register chat pattern
        this.registerChatPattern('coins', /You earned (\d+) coins?/);
        
        // Register listener
        this.registerEvents(new PatternListener());
    }
}

// Listener implements Listener interface
class PatternListener implements Xady.Listener {
    @Xady.EventHandler(Xady.EventPriority.NORMAL)
    onChatPattern(event: Xady.ChatPatternEvent) {
        if (event.getPatternName() === 'coins') {
            const amount = event.getMatch(1);
            console.log(`Earned ${amount} coins!`);
        }
    }
}

ChatPatternEvent API

getPatternName()

Returns the registered pattern name

const name = event.getPatternName(); // 'coins'

getMatch(index: number)

Returns specific regex capture group

const amount = event.getMatch(1); // First capture group

getFullMatch()

Returns full matched string

const full = event.getFullMatch(); // "You earned 50 coins"

getMatches()

Returns all matches array

const matches = event.getMatches();

Pattern Examples

Multiple Patterns in One Module

typescript 
export default class EconomyModule extends Xady.Module {
    private balance: number = 0;
    
    onEnable() {
        // Register patterns
        this.registerChatPattern('coin_earn', /You earned (\d+) coins?/);
        this.registerChatPattern('coin_spend', /You spent (\d+) coins?/);
        this.registerChatPattern('balance', /Balance: \$?(\d+)/);
        this.registerChatPattern('teleport', /You teleported to (\w+)/);
        this.registerChatPattern('kill', /(\w+) killed you/);
        
        // Register listener
        this.registerEvents(new EconomyListener(this));
    }
    
    addBalance(amount: number) {
        this.balance += amount;
    }
    
    getBalance(): number {
        return this.balance;
    }
}

class EconomyListener implements Xady.Listener {
    constructor(private module: EconomyModule) {}
    
    @Xady.EventHandler(Xady.EventPriority.NORMAL)
    onChatPattern(event: Xady.ChatPatternEvent) {
        const pattern = event.getPatternName();
        
        switch (pattern) {
            case 'coin_earn':
                const earned = parseInt(event.getMatch(1) || '0');
                this.module.addBalance(earned);
                this.module.getLogger().info(`+${earned} coins`);
                break;
                
            case 'coin_spend':
                const spent = parseInt(event.getMatch(1) || '0');
                this.module.addBalance(-spent);
                this.module.getLogger().info(`-${spent} coins`);
                break;
                
            case 'balance':
                const bal = parseInt(event.getMatch(1) || '0');
                this.module.getLogger().info(`Balance: ${bal}`);
                break;
                
            case 'teleport':
                const location = event.getMatch(1);
                this.module.getLogger().info(`Teleported to ${location}`);
                break;
                
            case 'kill':
                const killer = event.getMatch(1);
                this.module.getLogger().warn(`Killed by ${killer}!`);
                break;
        }
    }
}

Automatic Cleanup

Registered chat patterns are automatically unregistered when the module is disabled. No manual cleanup required!

Pattern Per Event (Cleaner)

typescript 
// If you prefer specific event names
class EconomyListener implements Xady.Listener {
    @Xady.EventHandler(Xady.EventPriority.NORMAL)
    onChatPattern(event: Xady.ChatPatternEvent) {
        // Handle all in one
        if (event.getPatternName() === 'coin_earn') {
            this.handleCoinEarn(event);
        }
    }
    
    private handleCoinEarn(event: Xady.ChatPatternEvent) {
        const amount = parseInt(event.getMatch(1) || '0');
        console.log(`+${amount} coins`);
    }
}

Module API Reference

Core Methods

getServer()

Returns Mineflayer bot instance (Spigot API compatibility)

const bot = this.getServer();
bot.chat("Hello!");

getBot()

Returns Mineflayer bot instance

const bot = this.getBot();

getName()

Returns module name

const name = this.getName();

getLogger()

Returns logger

this.getLogger().info("Message");
this.getLogger().warn("Warning");
this.getLogger().error("Error");

getCommand(name: string)

Returns command from module.yml

const cmd = this.getCommand("test");
if (cmd) {
    cmd.setExecutor({ ... });
}

registerEvents(listener: any)

Registers event listener

this.registerEvents(new MyListener());

registerChatPattern(name: string, pattern: RegExp)

Registers chat pattern for automatic message matching

this.registerChatPattern('coins', /You earned (\d+) coins?/);
// Listen via ChatPatternEvent

unregisterChatPattern(name: string)

Manually removes a chat pattern

this.unregisterChatPattern('coins');

getDataFolder()

Returns module data folder (lazy creation)

const folder = this.getDataFolder();
// %APPDATA%\Xady\data\ModuleName\

getConfig()

Returns config object

const config = this.getConfig();
const value = config.myKey;

saveDefaultConfig()

Copies default config.yml to data folder

this.saveDefaultConfig();

Command API

CommandExecutor Interface

typescript 
interface CommandExecutor {
    onCommand(
        sender: CommandSender,
        command: PluginCommand,
        label: string,
        args: string[]
    ): boolean | Promise<boolean>;
}

Implementation

typescript 
// Create executor class
class MyExecutor implements Xady.CommandExecutor {
    onCommand(sender, command, label, args): boolean {
        sender.sendMessage("Command executed!");
        return true; // Success
    }
}

// Register in module
const cmd = this.getCommand("mycommand");
if (cmd) {
    cmd.setExecutor(new MyExecutor());
}

Return Values

  • true - Command executed successfully
  • false - Command failed, shows usage
