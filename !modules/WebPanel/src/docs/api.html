WebPanel Modül API'si

WebPanel modülü, Xady framework'ü içerisindeki diğer modüllerin panele kendi sayfalarını, API uç noktalarını (endpoint) ve izinlerini ekleyebilmeleri için gelişmiş bir arayüz sağlar.

Nasıl Çalışır?

WebPanel API'sine, kendi modülünüzün onEnable() fonksiyonu içerisinden WebPanel modül örneğini çekerek erişebilirsiniz.

const webPanel = PaymentModule.getModule<WebPanelModule>("WebPanel");
const api = webPanel.webApi;

Not: WebPanel'in kendi modülünüzden önce yüklendiğinden emin olmak için module.json dosyanızda "dependencies": ["WebPanel"] tanımı yapmayı unutmayın.

Veri Türleri (Types)

API'yi kullanırken bilmeniz gereken temel TypeScript türleri şunlardır:

// Menü Öğesi (Sidebar)
type NavItem = { 
  id: string; 
  title: string; 
  path: string; 
  permission?: string; 
  scope?: "app" | "admin" 
};

// Sayfa (HTML) Görüntüleyici
type ViewHandler = (req: IncomingMessage, ctx: HttpHandlerCtx) => Promise<string> | string;

// Backend API Yönlendirici
type HttpHandlerCtx = { 
  session: { username: string; roles: string[]; permissions: string[] } | null; 
  hasPerm: (perm: string) => boolean 
};
type HttpHandler = (req: IncomingMessage, res: ServerResponse, ctx?: HttpHandlerCtx) => boolean | Promise<boolean>;

// İzin (Yetki) Tanımı
type PermissionDef = { 
  id: string; 
  description: string; 
  defaultRole?: string 
};

registerNav Menü Ekleme

webApi.registerNav(item: NavItem)

WebPanel'in sol menüsüne (Sidebar) yeni bir bağlantı butonu ekler.

testPanel.webApi?.registerNav({
    id: "payment_home",
    title: "Ödeme Sistemi",
    path: "/payment",
    permission: "payment.view" // Bu yetkiye sahip olmayanlar menüyü göremez
});

registerView Sayfa (HTML) Ekleme

webApi.registerView(path: string, handler: ViewHandler)

Belirtilen URL yoluna (path) girildiğinde SPA (Single Page Application) ortasına yüklenecek olan HTML içeriğini döndürür.

testPanel.webApi?.registerView("/payment", async(req, ctx) => {
    // İzin kontrolü yapabilirsiniz
    if (!ctx.hasPerm("payment.view")) return "<h1>Erişim Reddedildi</h1>";

    return `
        <div class="card">
            <div class="card-header"><div class="card-title">Ödeme</div></div>
            <div class="card-body">
                <button id="testBtn">Tıkla</button>
            </div>
        </div>
    `;
});

registerHttp Backend API Ekleme

webApi.registerHttp(handler: HttpHandler)

Web sunucusuna tamamen özel bir yönlendirme (HTTP Route) ekler. Frontend tarafında yazılan buton tıklamalarını (fetch) karşılamak için kullanılır.

Önemli: İsteği siz karşıladıysanız return true; döndürmelisiniz, aksi takdirde diğer router'lara geçer.

testPanel.webApi?.registerHttp(async (req, res, ctx) => {
    const method = req.method?.toUpperCase();
    
    if (req.url === "/api/payment/test" && method === "POST") {
        if (!ctx?.hasPerm("payment.use")) {
            res.writeHead(403);
            res.end("Yetkisiz");
            return true;
        }

        // ... İşlemler ...
        res.writeHead(200, { "Content-Type": "application/json" });
        res.end(JSON.stringify({ ok: true, msg: "İşlem Başarılı" }));
        return true; // İsteği yakaladığımızı belirtiriz
    }
    
    return false; // İstek bizimle alakalı değilse false döneriz
});

registerPermission Yetki Ekleme

webApi.registerPermission(perm: PermissionDef)

Sistemin veritabanına ve Admin Paneli (Roller/Kullanıcılar) kısmına yeni bir özel izin kaydeder. Yöneticiler bu izni onay kutusu (checkbox) şeklinde kullanıcılara atayabilir.

testPanel.webApi?.registerPermission({
    id: "payment.use",
    description: "Ödeme modülünü kullanabilir"
});

pushChat Sohbete Yazı Gönderme

webApi.pushChat(text: string)

WebPanel'in canlı sohbet (Chat) sayfasına sunucu kaynaklı ("server" tag'i ile yeşil renkte) bir sistem mesajı düşürür.

testPanel.webApi?.pushChat("Bir ödeme işlemi gerçekleştirildi!");

Yerleşik (REST) API Rotaları

WebPanel'in frontend ve backend arasındaki iletişimi sağlamak için kullandığı yerleşik HTTP rotaları. Dış modüller frontend üzerinden fetch ile bu adreslere istek atabilirler.

Kimlik Doğrulama & Profil (Auth)

MetodEndpointAçıklama
POST/api/loginGiriş yapar. Body: { username, password }. Çerez atar.
POST/api/logoutOturumu kapatır ve çerezi siler.
GET/api/meGiriş yapan kullanıcının bilgilerini (username, roles, permissions) döner.
PUT/api/me/passwordŞifre değiştirir. Body: { currentPassword, newPassword }

Dış Uygulamalar & API Key (Yetkilendirme)

Üçüncü parti uygulamalar (Discord botları, harici web siteleri vb.), WebPanel REST API uç noktalarına erişmek için oturum çerezleri (Cookie) yerine API Key kullanabilirler.

API Key, Yönetici Paneli üzerinden ("API Anahtarları" sekmesinden) oluşturulur. Anahtara özel olarak hangi yetkilere (örn: chat.send, admin.users.read) sahip olacağı seçilir.

API Key Nasıl Kullanılır?

Dış uygulamanızdan istek atarken, oluşturulan API Key değerini HTTP başlıklarına (Headers) eklemeniz yeterlidir. WebPanel sunucusu, isteğin yetkisini otomatik olarak tanır ve CSRF korumasını API Key'ler için devre dışı bırakır.

Yöntem 1: X-API-Key Başlığı (Önerilen)

fetch("http://localhost:8787/api/chat", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "X-API-Key": "xady_1234567890abcdef"
    },
    body: JSON.stringify({ text: "Merhaba Xady!" })
});

Yöntem 2: Authorization Başlığı (Bearer Token)

fetch("http://localhost:8787/api/chat", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer xady_1234567890abcdef"
    },
    body: JSON.stringify({ text: "Merhaba Xady!" })
});
MetodEndpointAçıklama
GET/api/admin/apikeysMevcut API Key'leri listeler. (İzin: admin.apikeys.read)
POST/api/admin/apikeysYeni bir API Key oluşturur. Body: { description, permissions: [] } (İzin: admin.apikeys.write)
PUT/api/admin/apikeysAPI Key izinlerini günceller. Body: { id, description, permissions: [] } (İzin: admin.apikeys.write)
DELETE/api/admin/apikeysAPI Key'i siler. Body: { id } (İzin: admin.apikeys.write)

Sohbet (Chat)

MetodEndpointAçıklama
GET/api/chat/historyGeçmiş sohbet mesajlarını sayfalar (pagination) halinde döndürür. Parametreler: ?offset=0&limit=50 (İzin: chat.view)
GET/api/chat/streamEventSource (SSE) kullanarak canlı sohbet akışını başlatır. Yeni mesajlar anlık olarak gelir. (İzin: chat.view)
POST/api/chatSohbete yeni bir mesaj yollar. Body: { text: "Mesaj" } (İzin: chat.send)

Kullanıcı Yönetimi (Admin)

MetodEndpointAçıklama
GET/api/admin/usersSistemdeki tüm kullanıcıları listeler. (İzin: admin.users.read)
POST/api/admin/usersYeni kullanıcı oluşturur. Body: { username, password, roles: [] } (İzin: admin.users.write)
PUT/api/admin/usersKullanıcıyı düzenler (Şifre, roller, ban, özel izinler). Body: { username, password?, roles?: [], bannedUntil?, banReason?, customPermissions?: [] } (İzin: admin.users.write)
DELETE/api/admin/usersKullanıcıyı siler. Body: { username } (İzin: admin.users.write)

Roller & İzinler (Admin)

MetodEndpointAçıklama
GET/api/admin/rolesVeritabanındaki tüm rol tanımlamalarını getirir. (İzin: admin.roles.read)
PUT/api/admin/rolesRolleri ve yetkilerini günceller. Body: { roles: { admin: { permissions: ["*"] } } } (İzin: admin.roles.write)
GET/api/admin/permissionsHem çekirdek hem de modüller tarafından kayıt edilmiş ("registerPermission") tüm yetkilerin tam listesini döner.

Modüller (Admin)

MetodEndpointAçıklama
GET/api/modulesYüklü olan tüm Xady modüllerini ve durumlarını (enabled/disabled) listeler. (İzin: modules.view)
POST/api/modules/toggleBir modülü açar veya kapatır. Body: { name: "Payment", enabled: true/false } (İzin: modules.manage)

Örnek: Butonla Chate Mesaj Yazdırma (Full Stack)

Hem Frontend'de bir buton oluşturup hem de Backend'de bu butonu dinleyerek Minecraft / Panel sohbetine mesaj göndermenin tam örneği:

export default class PaymentModule extends Xady.Module {
    onEnable() {
        const web = PaymentModule.getModule<WebPanelModule>("WebPanel");
        const client = this.getClient();

        // 1. Backend API (Tıklamayı dinleyecek sunucu)
        web.webApi?.registerHttp(async (req, res, ctx) => {
            if (req.url === "/api/payment/send-msg" && req.method === "POST") {
                // Sadece yetkili olanlar basabilsin
                if (!ctx?.session) {
                    res.writeHead(401); res.end(); return true;
                }
                
                // Minecraft sunucusuna chat mesajı yolla
                client.getBot()?.chat(`[Sistem] ${ctx.session.username} butona bastı!`);
                
                res.writeHead(200); res.end(JSON.stringify({ ok: true }));
                return true;
            }
            return false;
        });

        // 2. Frontend HTML (Kullanıcının göreceği buton)
        web.webApi?.registerView("/payment", async () => {
            return `
                <div class="card">
                    <div class="card-body">
                        <button id="test-btn" class="btn btn-primary">Chate Mesaj Gönder</button>
                    </div>
                </div>
                <script>
                    // Sayfa yüklendiğinde butonu dinle
                    document.getElementById('test-btn').addEventListener('click', async () => {
                        try {
                            await fetch('/api/payment/send-msg', { method: 'POST' });
                            alert("Mesaj gönderildi!");
                        } catch(e) {
                            alert("Hata oluştu");
                        }
                    });
                </script>
            `;
        });
    }
}
